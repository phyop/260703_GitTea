# GitTea Git Learning Article

This project contains the Medium article and visual assets for a Git/Gitea learning story:

**From Optical Engineer to Software Engineer: The First Time I Understood Git Through Gitea**

The article focuses on understanding Git through its core workflow:

- Working Tree
- Staging Area
- Local Repository
- Remote Repository
- `git add`
- `git commit`
- `git push`
- Source vs generated output
- Merge conflict reasoning

## Files

- `medium-git-mental-model-article.md` - Medium article draft.
- `generate_git_mental_model_diagrams.ps1` - Diagram generation script.
- `medium-assets/` - GitTea article diagrams.

## Project Isolation

This folder is dedicated to the GitTea article project only. Content from other projects should not be placed here.
